# Hangman

A simple **Hangman game** made in C++.

## Features

* Randomly selects a word
* 5 lives
* Guess letters to reveal the word
* Win or lose detection
* Option to play again

## How to Run

Compile and run the C++ file:

```bash
g++ main.cpp -o hangman
./hangman
```

## Made With

* C++
* `<vector>`
* `<string>`
* `<random>`
